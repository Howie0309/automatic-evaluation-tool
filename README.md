# 评估工作台 · Eval Space

一个在本机运行的评估工作台，集中使用两套工具：**自动评估（Judge Studio）** 和 **截图与视觉评估**。

| 工具 | 适合做什么 | 输入 | 产出 |
| --- | --- | --- | --- |
| 自动评估 | 按自定义标准，批量评价已有的模型回答或其他内容 | Excel 数据集、评审 Prompt，可选规则附件和图片 | 逐条评估结果、分数统计、交互报告、Excel / CSV / JSON |
| 截图与视觉评估 | 批量向 ChatGPT 网页版提问，留存回答画面并评价视觉效果 | 一组问题、PC 或手机视图，可选视觉评审 Prompt | 长截图、模型评估、人工评级与备注、整体分析、Excel |

已有回答数据，使用自动评估；需要先到网页提问、观察回答的实际呈现效果，使用截图与视觉评估。两套工具可以单独使用，也可以通过工作台统一进入。

## 安装与启动

推荐使用 **Node.js 24**。截图功能目前按 **macOS + Google Chrome** 环境适配，还需要能正常使用 ChatGPT 网页版的账号。

首次下载后，在项目根目录安装两套工具的依赖：

```bash
git clone https://github.com/Howie0309/automatic-evaluation-tool.git
cd automatic-evaluation-tool
npm install
npm --prefix pc-screenshots install
```

在 macOS 上双击根目录的 **启动评估工作台.command**，浏览器会打开 [本地工作台](http://127.0.0.1:3088)。也可以在根目录运行：

```bash
npm run platform
```

进入工作台后，点击左侧的「自动评估」或「截图与视觉评估」。对应服务会按需启动。工作台还可以统一查看历史记录、打开报告，并把记录关联到项目。

使用启动文件运行时，可双击 **停止评估工作台.command** 停止工作台及它启动的工具；使用命令行运行时，按 `Ctrl+C` 退出。停止前请先保存或完成正在执行的任务。

## 工具一：自动评估（Judge Studio）

### 能做什么

- 自定义 System Prompt 和 User Prompt，用自己的评价维度、标准和输出格式批量评审。
- 通过 OpenAI 或 OpenAI 兼容 API 调用模型，支持配置模型、并发数和失败重试。
- 上传 Excel 数据集，通过 `{{列名}}` 把每行内容填入 Prompt；支持选择 Excel 内嵌图片进行多模态评估。
- 附加 Excel 或 PDF 评审规则，供整批数据共用；涉及图片或 PDF 页面时，需要支持视觉输入的模型。
- 暂停、继续或中断批量评估，保留已完成的结果。
- 查看逐条结果、分数统计和独立交互报告，导出 Excel、CSV、JSON。

### 怎么使用

1. 在工作台打开「自动评估」。
2. 填写 **System Prompt**，说明评审角色、标准和预期输出；填写 **User Prompt 模板**，引用待评内容。
3. 选择服务商和模型，填写 API 地址与 API Key；有统一评分标准时，可上传规则附件。
4. 上传 `.xlsx` 文件，选择工作表和评估范围，为 Prompt 中的变量选择对应的 Excel 列；需要看图时勾选待评图片列。
5. 检查预览，设置并发数和重试次数，点击「开始评估」。
6. 在结果区查看输出，或从「已保存记录」打开交互报告、下载结果。

例如，Excel 第一行为列名：

| query | answer |
| --- | --- |
| 请介绍一下杭州 | 杭州是浙江省省会…… |

User Prompt 可以写为：

```text
请根据评分标准评估以下回答：
问题：{{query}}
回答：{{answer}}
请返回 JSON，包含 score 和 reason。
```

列名可以自定义，不限于 `query` 和 `answer`。模型可以输出 JSON 或纯文本；如需分数统计，在「分数字段路径」填写 `score` 等实际输出字段。

**单独启动：** 在根目录运行 `npm start`，访问 [自动评估](http://127.0.0.1:3077)。规则附件、图片限制与自动评估云端部署等进阶说明见 [自动评估详细说明](docs/automatic-evaluation.md)。

## 工具二：截图与视觉评估

### 能做什么

- 当前适配 **ChatGPT 网页版**，批量发送问题并等待回答生成后截取长图。
- 支持 PC 视图和两种手机宽度视图（390 / 440），按批次保存问题与截图。
- 支持逐行粘贴问题，或导入 TXT、CSV、Excel；CSV / Excel 取第一列作为问题。
- 截图失败可重试，队列可暂停和继续；截图间隔、休息节奏等可在设置中调整。
- 调用视觉模型逐条评估截图，支持人工评级、备注、筛选与批次整体分析。
- 导出 Excel，可选择导出字段及是否嵌入截图；配置额外的 popo 上传工具后，可发布分享网页。

### 怎么使用

1. 在工作台打开「截图与视觉评估」，点击右上角「启动 Chrome」。
2. 在弹出的专用 Chrome 窗口中登录 ChatGPT，确认可以正常提问。工具使用这个窗口的登录状态，首次使用需手动登录。
3. 点击「新建批次」，填写名称，选择 PC 或手机视图，粘贴问题（每行一条）或导入文件。
4. 点击「创建并开始截图」，在批次里查看进度。若遇到人机验证，在专用 Chrome 中手动处理后继续。
5. 如需模型评估，打开「设置」，填写 OpenAI 兼容的视觉模型 API 地址、API Key、模型名和评审 Prompt，然后选择「评估选中」或「评估全部待评估」。**只截图无需配置模型 API。**
6. 打开截图查看大图、添加人工评级和备注；完成后生成整体分析或导出 Excel。

截图时需要保持本机服务和专用 Chrome 运行。该工具依赖本机浏览器及登录状态，当前按本地使用设计；直接把代码放到云端不会自动获得本机的登录状态。

**单独启动：** 在根目录运行 `npm --prefix pc-screenshots start`，访问 [截图与视觉评估](http://127.0.0.1:3210)。截图参数、分享配置和命令行用法见 [截图工具详细说明](pc-screenshots/README.md)。

## 数据保存与更换电脑

| 内容 | 本地位置 |
| --- | --- |
| 自动评估的原始 Excel、图片附件和评估结果 | `data/` |
| 截图批次、截图和评估记录 | `pc-screenshots/batches/` |
| 截图工具设置，包括模型 API Key | `pc-screenshots/config.json` |
| 截图专用 Chrome 的浏览器资料 | `pc-screenshots/.chrome-profile/` |
| 工作台项目关联信息 | `data/platform/projects.json` |

更换电脑时，先停止相关任务和服务，再备份 `data/` 与整个 `pc-screenshots/batches/`。如需保留截图工具配置，可单独备份 `config.json`，其中含密钥，需妥善保管。新电脑重新安装依赖，并在截图工具启动的专用 Chrome 中重新登录。

自动评估的 API Key 仅保留在当前浏览器会话中，不写入项目文件；截图工具的 API Key 保存在本机 `config.json`。上述业务数据、浏览器资料和本机配置均不随源码上传 GitHub。调用模型时，所选待评内容会发送到你配置的模型接口，并产生相应 API 用量。

仓库另保留「生成式 UI 实验室」作为辅助演示入口，使用说明见 [seed-demo/README.md](seed-demo/README.md)；工作台管理说明见 [platform/README.md](platform/README.md)。
