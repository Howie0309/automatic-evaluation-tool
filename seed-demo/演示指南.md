# 生成式 UI 演示指南

打开 http://127.0.0.1:8787 ，默认进入“模板图鉴”。现在按**完整回答**展示，按钮和输入框等零件不再算作模板。

## 静态内容模板

主图鉴默认先显示静态图文分类卡。选择“呈现方式 → 静态展示”可以查看六项：图文分类卡、图文对比卡、步骤卡、时间轴、原理关系示意图、生成式表格。它们以完整信息排版为目标，不添加无必要的滑块或按钮。

图文分类双端保持左图右文；图文对比只用于两个对象，当前无实拍时按规则整组退为文字。需要图片预览时，在主应用添加名称为“相机 A”“相机 B”的两张可靠实拍，再重新选中。步骤逐项交代操作位置、动作与注意事项；时间轴使用统一粒度的确切时间；关系图只解释一个关系；表格仅在状态一列使用符号。

这些静态条目的来源是你提供的六种规范，不作为官方案例或GPT-6实测输出。主图鉴现有25项：6个静态规范示例＋19个公开交互案例。HTML、Markdown和JSON同步包含二者。

## 交互样式的演示顺序

1. **图文菜单与人数联动**：先看一整块图文规划，改人数，观察采购量，再勾选准备清单。
2. **多方案权重与推荐排序**：改续航、便携和价格权重，观察推荐、排序与对比表。
3. **结构探索与局部讲解**：点自行车部件，切换对应图示和说明；拖动挡位查看传动示意。
4. **抽样分布与参数实验**：改变样本数再抽样，观察分布；或体验三门问题的选择、揭晓和换门。
5. **成本预算与边界校验**：20人时总成本700；改30人总成本950并提示超支；0人保留场地费，人均不适用；空输入显示错误。
6. **其他完整回答**：体验路线站点、三日预算、衣橱、情绪板、增长曲线、看板、假名测验、小游戏和鼓机。鼓机点击播放才发声，离开图鉴预览会停止。

按图文规划、地图与行程、交互讲解、模拟实验、参数计算、偏好决策、学习测验、创意选配、数据看板、内嵌应用这10类归纳，共19个有出处的公开样例：11个官方演示、8个第三方观察。每项可直接查看来源；部分项目可展开实际来源截图，分账可打开官方原演示。本地预览是独立重建，使用标明为示例的数据和矢量插图，不当作原始截图或像素级还原。

“本地回放到对话”直接切换回放模式，不调用模型；“复制示例提问”可用于你自己在ChatGPT尝试。当前工具的实时生成仍使用已配置的OneAPI和本工具组件，不保证复现ChatGPT私有运行时。

主图鉴可以筛选场景和证据等级，导出含6个静态展示和19个交互预览的独立HTML、Markdown或JSON。10类目前仅有运行时名称的服务样式放在“仍需核实的样式线索”，不计入已核实样例。

## 技术附录与原有业务模板

在图鉴底部展开“已有业务模板与技术附录”。原有六种内容模板和工具从“原有业务模板与工具”进入；70个原子名称与313个宿主名称从“组件名称技术附录”进入。两者均可返回主图鉴。

左侧示例问题现在共有57项：25个完整模板回放与32个原有场景。新图鉴中的本地样例不冒充配置模型的真实生成效果。

## 建议演示顺序

1. **团建预算**：编辑餐饮单价为 80，再锁定餐饮。点击“增加交通费，人数改为 40”。原预算表更新，锁定的餐饮金额保留，物料数量变成 40，新增交通费。
2. **方案比较**：调整预算友好、参与体验和天气适应权重，观察加权得分及排名。示例评分均为虚构。
3. **排程检查**：默认示例含有时间重叠和依赖冲突。将“制作原型”开始时间改成 10:00，冲突解除。桌面端也可拖动任务到其他日期。
4. **原理关系图**：查看本地模型请求流程，点击对象查看说明。
5. **图片标注、排队模拟**：点击标注查看说明，或逐分钟模拟排队、增加窗口比较结果。
6. **模板退化**：选择退化示例，展示缺少图片、图标、日期和精确结构条件时如何保留全部文字。

“预录回放”不会调用模型，只用于展示组件与交互。接入自己的 OneAPI 后，选择“实时生成”才能演示真实模型输出。模型名称按网关配置展示，不预设任何模型已经可用。展开“查看模型输出”可查看模型名称、首字延迟、总耗时、DSL、编译诊断及当前状态。耗时是本页面观察到的时间，回放耗时不代表模型性能。

## 六种内容模板

| 模板 | 标签 | 布局与退化规则 |
| --- | --- | --- |
| 图文分类卡 | ImageList / ImageCard | 至少三个对象，手机和桌面均左图右文；图片与素材对象名称对应，任一缺图或加载失败则整组退为文字。 |
| 图文对比卡 | ImageCompare / ImageCard | 两个对象左右并排实拍图、图下配文；缺任一实拍图则退为文字；超过两个对象改用分类列表。 |
| 步骤卡 | GuideSteps / GuideStep | 纵向图标加步骤正文；任一步缺少支持的图标则整组去掉图标。可附可靠平台链接。 |
| 时间轴 | EventTimeline / Event | 日期浅色块、右侧事件；按日期排序；日期必须真实有效且粒度一致，否则整组文字呈现。 |
| 原理关系示意图 | RelationDiagram / DiagramNode / DiagramEdge | 命名色块、箭头及连线，同对象同色；涉及精确形态或空间比例时设置 precise，退为文字。 |
| 生成式表格 | DataTable / DataRow | 至少两个对象且各有两个属性；最多一列使用符号或重点字色，不能叠加；未知状态无装饰。 |

模板描述和示例均出现在“组件库”。适用条件和退化规则同时进入默认系统提示词；已有自定义提示词时，请根据需要恢复默认或合并新增规则。

## 图片素材

点击顶部“图片素材”，填写对象名称、素材类型，再上传 JPG、PNG 或 WebP（单张上限 5 MB）。素材只保留在当前页面会话中，刷新后需重新添加。

上传照片的名称应与模型生成的 ImageCard 标题一致；模型使用素材 ID 引用图片。图文对比需要两张标为“实拍照片”的图片，建议构图及角度接近。系统不会自动检索图片，也不会用随机网络图片填补空缺。是否确实为对应对象的可靠实拍图片，需要素材提供者确认。

本地预置圆形、三角形和正方形插图，用于分类和标注演示，不能充当实拍对比图。

ImagePanel 也可以引用最近从聊天输入框上传的图片。标注位置为模型给出的示意坐标，不等同于精确检测。

## 多轮局部修改的范围

目前支持对已有 BudgetTable 的人数、预算上限和项目行执行 Patch（修改、新增、删除）。整组更新先验证再应用，锁定行不可被模型修改。取消、截断或有校验错误的输出不会应用补丁。其他组件可交互并回传状态，但尚不支持通用的跨消息局部重写。

数值状态和素材仅保留在当前页面中，刷新或新建对话不会保留预算编辑。API 配置单独保存在本机服务端，重启后仍有效。

运行 `npm test` 可检查接口适配、配置保护、模板编译、流式状态、退化、时间冲突和补丁的原子更新。


## 联网搜索的使用

输入框上方可选择“按需联网 / 始终联网 / 关闭联网”。默认按需模式基于关键词判断，适合最新、价格、官方入口、开放时间等需求；要确保本轮检索可选“始终联网”。回放不会执行联网。

顶部“搜索设置”默认使用 Bing 公开搜索，无需额外密钥；也支持填写独立的 Tavily API Key。用下方“测试联网”验证本机网络和当前已保存的服务，不调用模型。Bing 的可用性及结果相关度受网络和搜索服务影响。

成功搜索后，回答上方显示来源数量与耗时，展开可查看标题、链接和摘要。模型可用 [1] 等编号引用，来源区域来自真实搜索结果。资料为搜索摘要，不表示已阅读网页全文。搜索失败时会提示，模型不得声称已联网核实。

只有当前问题文字会作为搜索词，不会把界面状态快照、API Key 或图片内容发送给搜索服务。使用 Tavily 时可能消耗该服务额度，模型调用仍按原网关规则计费。

## 新版提示词

“什么时候用界面”按六种模板的适用需求、内容阈值、布局与退化条件逐项选择，同时保留交互工具规则。普通原理解释可以在适合时使用关系示意图；闲聊、情绪或单一简单事实继续用文字。未来规划与已发生事件分开处理。

新版默认规则已启用；旧版自定义提示词仍保留在浏览器旧存储键下。新版自定义内容使用独立键，不会自动把旧的“只允许交互时使用界面”约束带回来。
