# 本地使用

双击 `start.command` 启动，然后打开 http://127.0.0.1:8787 。保持启动窗口开启，按 Control + C 停止。

也可以在当前文件夹运行：

```sh
node --env-file-if-exists=.env server.js
```

不配置模型密钥也能使用全部预录示例、组件库、提示词编辑及独立的搜索测试。实时生成需要火山方舟 API Key，以及该账号可调用的模型。

## 开启实时生成

推荐直接点页面顶部的“模型设置”，选择 OneAPI / New API，填写接口地址、模型名称和网关令牌，然后点“保存并启用”。支持 OpenAI 兼容的 Chat Completions 接口；OneAPI 地址可填写 `https://你的域名` 或 `https://你的域名/v1`。模型名称必须与网关中的名称一致，图片输入需要模型和渠道支持。

配置只保存在本机 `.local-config.json` 中（文件权限 600），不会将密钥返回浏览器。保存后无需重启。设置入口仅允许本机访问，隧道访客不能读取或修改。此文件含密钥，请勿分享或打包。网页配置优先于环境变量；若需恢复纯环境变量配置，停止服务、删除 `.local-config.json` 后重启。

OneAPI 不发送火山方舟专用的思考参数，思考行为由网关及模型决定。实际请求会消耗网关额度。

将 `.env.example` 复制为 `.env`，在本机编辑并填写 `ARK_API_KEY`。如默认模型未开通，将 `ARK_MODEL` 改成账号可用的模型 ID 或推理接入点 ID，保存后重启服务。

`.env` 含密钥，不要提交、分享或打包。无需将密钥发到聊天里。

服务只监听本机 `127.0.0.1`。实时生成会把输入文字和附带图片发送到配置的火山方舟接口，并消耗该账号额度。

## 排查

- 地址无法访问：确认启动窗口仍在运行，且端口未被其他程序占用。
- `EADDRINUSE`：8787 端口已占用，关闭旧服务或在 `.env` 中设置其他 `PORT`。
- 无实时生成选项：确认 `.env` 内已填写 `ARK_API_KEY` 并重启。
- 401/403：检查密钥及模型权限；400/404：检查账号可用的模型 ID。

原始项目的分享功能见 README.md；本地部署无需运行 share.sh。
