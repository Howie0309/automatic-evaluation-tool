# 生成式UI演示

按需求选择图文卡片、步骤、时间轴、关系示意图、表格或交互工具的本地演示。支持自己的 OneAPI / New API，以及服务端联网搜索。

## 启动

双击 `start.command`，或在当前目录运行：

```sh
npm start
```

打开 http://127.0.0.1:8787 。需要 Node.js 22 或更新版本，不需要安装第三方依赖。

## 模型与联网

- **模型设置**：填写接口地址、实际可用的模型名称和令牌。保存后立即生效。
- **联网搜索**：输入框上方选择“按需联网 / 始终联网 / 关闭联网”。默认按需模式通过关键词判断是否需要外部核验；需要强制查找时选“始终联网”。
- **搜索设置**：默认 Bing 公开搜索，无需密钥；可切换到 Tavily Search API。提供“测试联网”按钮，实际检索但不调用模型。
- **来源**：实时回答前显示搜索状态，成功后可展开来源链接和摘要；模型通过编号引用对应依据。检索失败会明确提示。
- **预录回放**：只展示预设内容，不执行搜索或调用模型。包含 57 个场景（25个完整模板回放＋32个原有场景）。

联网由本地服务先检索、再向模型提供资料，兼容现有 Chat Completions 和火山方舟 Responses 接口。当前联网资料是搜索摘要，不是网页全文；结果质量受搜索服务影响。没有把当前聊天助手的浏览能力或账户凭证嵌入到演示程序。

## 呈现规则

“系统提示词”中已按六种模板的场景、内容条件、布局和退化规则重写选择逻辑。分类、比较、指南、时间事件、原理关系、属性汇总均可使用界面，不要求一定存在数字交互。条件不满足时整组退化并保留信息。

新版默认提示词使用独立的浏览器存储键；旧版自定义提示词未删除，但不会继续作为新版默认规则。

## GPT-6 完整回答样式图鉴

默认打开“模板图鉴”，共25项：6种用户提供的静态内容模板，以及19个公开交互案例（11个官方演示、8个第三方观察）。可按“全部呈现 / 静态展示 / 可交互”筛选，静态模板默认排在前面。新增图文分类、双对象图文对比、步骤、时间轴、关系示意和生成式表格，按原规范保留整组退化和信息不减规则。覆盖结构探索、图文聚餐、衣橱、路线、概率实验、分账、储蓄、小游戏、设计情绪板、指标看板、套餐估算、鼓机、识字测验、多日预算、偏好比较和成本预算等。

每项提供完整预览、呈现方式、关键模块、案例或规范来源、适用需求和边界。静态模板标为“用户规范”，不混入19个已核实公开案例。部分实测项目可展开来源截图；分账项目可打开官方原演示。图片是本地矢量示意、数值是假设时均标注。所有预览在本地交互，“本地回放到对话”明确切换回放模式，不调用当前配置模型。

模板名为研究归纳，不是官方固定模板编号；生成式布局可以继续组合，19项不代表全部可能样式。10类仅有运行时名称的服务样式单列“待核实”，不伪造预览。

导出 [独立互动HTML](./public/reference/template-atlas.html)、[完整说明](./research/GPT-6完整回答样式图鉴.md) 和 JSON，或运行 `node scripts/build_template_materials.js` 重建材料。系统提示词新增整块回答的组织原则，内部回放标签不暴露为模型可用接口。

“已有业务模板与技术附录”里保留原有工具的技术说明，以及上一版70个原子名称和313个宿主名称的研究目录。原子名称不再作为完整模板计数。原技术材料仍见 [ChatGPT组件清单](./research/ChatGPT组件清单.md)。

## 本地数据

- 模型密钥：`.local-config.json`。
- 搜索密钥：`.local-search.json`。
- 上述文件权限均为 600，且已加入 Git 忽略。不要分享这些文件或把它们打包。
- 用户图片、预算编辑与对话只保留在页面会话中。
- 服务只监听 `127.0.0.1`。设置及搜索测试入口仅限本机页面访问。

`share.sh` 是原项目附带的临时分享脚本，本地演示无需运行。对外分享前需配置访问码和调用限额；API Key 不能发给访客。

详情见 [演示指南](./演示指南.md) 和 [本地部署说明](./本地部署说明.md)。执行 `npm test` 验证请求适配、模板、状态更新及联网搜索。

搜索接口参考：[Bing 搜索 RSS](https://blogs.bing.com/search/2005/1/RSS-Feeds-for-Search-Results/)、[Tavily Search API](https://docs.tavily.com/documentation/api-reference/endpoint/search)。
